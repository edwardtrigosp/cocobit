Atajos

Seis atajos que usarás a diario

Shift+Tab

Cambia el modo de permisos: manual, aceptar ediciones o plan.

/init

Crea un CLAUDE.md con el contexto de tu proyecto.

@

Menciona un archivo para incluirlo en la conversación.

!

Ejecuta un comando de shell y pasa la salida a la sesión.

/compact

Resume la conversación para liberar contexto.

Esc Esc

Con el prompt vacío, abre el menú para rebobinar.
