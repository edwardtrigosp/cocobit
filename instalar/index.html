Instalar Claude Code

Requisitos, el comando para tu sistema, el primer inicio de sesión y cómo mantenerlo actualizado. Cinco minutos.

Lectura: 6 minRevisado: noviembre de 2026
En esta página
  1. Requisitos
  2. Instala según tu sistema
  3. Inicia y conecta tu cuenta
  4. Actualiza y diagnostica
  5. Desinstalar

Requisitos

  • Sistema: macOS 13+, Windows 10 (1809+) o Windows Server 2019+, Ubuntu 20.04+, Debian 10+ o Alpine 3.19+.
  • Equipo: 4 GB de RAM o más, procesador x64 o ARM64 y conexión a internet.
  • Shell: Bash, Zsh, PowerShell o CMD.
  • Cuenta: un plan Pro, Max, Ultra, Team o Enterprise, o una cuenta de Claude Console. El plan gratuito de Claude.ai no incluye Claude Code.
  • Node.js 22+: solo si instalas con npm.

Instala según tu sistema

Instalador nativo (recomendado). Se actualiza solo en segundo plano.

Terminal 
curl -fsSL https://claude.ai/install.sh | bash

Homebrew. No se actualiza solo; usa brew upgrade claude-code.

Terminal 
brew install --cask claude-code

Instalador nativo (recomendado). Funciona igual en Linux y en WSL.

Terminal 
curl -fsSL https://claude.ai/install.sh | bash

También hay paquetes para apt, dnf y apk: consulta la documentación.

PowerShell (recomendado).

PowerShell 
irm https://claude.ai/install.ps1 | iex

Símbolo del sistema (CMD).

CMD 
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

WinGet. No se actualiza solo; usa winget upgrade Anthropic.ClaudeCode.

PowerShell 
winget install Anthropic.ClaudeCode

Git for Windows: es recomendable, pero no obligatorio. Sin él, Claude Code usa PowerShell como shell; con él tiene la herramienta Bash.

Alternativa: npm

Requiere Node.js 22 o superior. No uses sudo.

Terminal 
npm install -g @anthropic-ai/claude-code@latest

Inicia y conecta tu cuenta

  1. Comprueba que quedó instalado:

    Terminal 
    claude --version

  2. Entra en la carpeta de tu proyecto y arranca Claude Code:

    Terminal 
    cd mi-proyecto
claude

  3. La primera vez se abre el navegador para iniciar sesión. Dentro de la sesión puedes usar /login y /logout cuando quieras.

  4. Pide algo concreto, por ejemplo: «Explícame la estructura de este proyecto».

Actualiza y diagnostica

La instalación nativa se actualiza sola en segundo plano. Para forzarlo:

Terminal 
claude update

Si algo falla, claude doctor revisa la instalación sin iniciar sesión. Dentro de una sesión, /doctor también propone correcciones.

Terminal 
claude doctor

Canal de actualizaciones: en /config puedes elegir latest (por defecto) o stable.

Desinstalar

Instalación nativa en macOS, Linux o WSL:

Terminal 
rm -f ~/.local/bin/claude
rm -rf ~/.local/share/claude

Si instalaste con Homebrew, WinGet o npm, desinstala con ese mismo gestor. Más detalles en la guía oficial de problemas de instalación.
