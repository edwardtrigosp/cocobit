Atajos y comandos

Todo en una página. Puedes imprimirla y tenerla junto al teclado.

Teclado

Shift+Tab

Cambia el modo de permisos.

Esc Esc

Con texto: borra el borrador. Con el prompt vacío: abre el menú de rebobinado.

Ctrl+C

Interrumpe lo que está haciendo. Sin nada en curso, limpia el prompt; dos veces, sale.

Ctrl+R

Busca en el historial de prompts.

Ctrl+B

Pasa comandos y agentes a segundo plano (en tmux, dos veces).

Ctrl+G

Abre el prompt en tu editor de texto.

Ctrl+V

Pega una imagen del portapapeles (en Windows y WSL, Alt+V).

Ctrl+J

Salto de línea en cualquier terminal.

Shift+Enter

Salto de línea en iTerm2, WezTerm, Ghostty, Kitty, Warp y Windows Terminal 1.25+. En otros, ejecuta /terminal-setup.

!

Al inicio del prompt: ejecuta un comando de shell.

@

Autocompleta y menciona archivos.

/

Abre la lista de comandos y skills.

Comandos con /

/init

Crea CLAUDE.md

/memory

Edita la memoria

/plan

Entra en plan mode

/clear

Conversación nueva

/compact

Resume y libera contexto

/resume

Retoma una conversación

/model

Cambia de modelo

/context

Uso del contexto

/usage

Coste y límites

/mcp

Servidores MCP

/plugin

Plugins y marketplaces

/hooks

Hooks activos

/config

Ajustes

/doctor

Diagnóstico

/help

Ayuda

Desde la terminal

Terminal 
claude                      # inicia en la carpeta actual
claude -c                   # continúa la última conversación
claude -r <nombre>          # reanuda una conversación
claude -p "<tarea>"         # modo no interactivo
claude --permission-mode plan
claude update               # actualiza
claude doctor               # diagnostica la instalación
claude mcp list             # servidores MCP
