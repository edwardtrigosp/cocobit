Permisos: deja de aprobar lo mismo

Con reglas allow, ask y deny decides qué puede hacer Claude sin preguntar:

.claude/settings.json 
{
  "permissions": {
    "allow": ["Bash(git diff *)"],
    "deny": ["Read(./.env)"]
  }
}

Se evalúa deny, luego ask, luego allow. Un deny no se puede anular con allow.

Hooks

Un hook ejecuta un comando en un momento concreto: antes o después de usar una herramienta, al enviar un prompt, al terminar… Sirve para formatear código tras cada edición, bloquear comandos peligrosos o avisarte cuando Claude acaba.

Eventos más usados: SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, Notification, Stop y SessionEnd.

.claude/settings.json 
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          { "type": "command", "command": "echo Archivo modificado" }
        ]
      }
    ]
  }
}

matcher filtra por herramienta; si lo omites, el hook aplica a todas. Escribe /hooks para ver los que tienes activos.

Ojo: los hooks ejecutan comandos con tus permisos. Revisa los que vengan de plugins o repositorios ajenos antes de activarlos.

Scripts con claude -p

El modo no interactivo ejecuta una tarea y devuelve el resultado; ideal para scripts y CI.

Terminal 
claude -p "Explica qué hace el módulo de auth"
claude -p "Resume este proyecto" --output-format json
cat error.log | claude -p "Explica la causa raíz"

--output-format acepta text, json o stream-json. Con --allowedTools limitas qué herramientas puede usar.

GitHub Actions

Desde Claude Code, ejecuta /install-github-app para configurar la app y el flujo (solo repositorios de github.com). La acción es anthropics/claude-code-action@v1 y necesita el secreto ANTHROPIC_API_KEY o CLAUDE_CODE_OAUTH_TOKEN (que se genera con claude setup-token).
