Herramientas de Claude

Claude Code vive en varios lugares. Esta guía explica qué ofrece cada uno y cuándo conviene usarlo.

Terminal (CLI)

La experiencia completa: edita archivos, ejecuta comandos y gestiona el proyecto desde la línea de comandos. Es la base de todo lo demás y la que permite automatizar con claude -p.

Cómo instalarla →

App de escritorio

Para macOS y Windows (x64 y ARM64); en Linux está en beta para Ubuntu y Debian. Su pestaña Code permite revisar diffs visualmente, tener varias sesiones en paralelo y programar tareas. Requiere un plan de pago.

Guía oficial de la app de escritorio

Web: claude.ai/code

Claude Code desde el navegador, sin instalación local. Útil para trabajar desde otro equipo o lanzar tareas largas que siguen corriendo en la nube.

Claude Code en la web

VS Code y JetBrains

  • VS Code (también funciona en Cursor): diffs dentro del editor, menciones con @ y revisión de planes. Documentación
  • JetBrains (IntelliJ, PyCharm, WebStorm…): plugin que trabaja junto a la CLI, que debes instalar aparte. Documentación

Claude en Chrome

Extensión de Chrome que Claude Code usa para abrir tu app, hacer clic, leer la consola y depurar. Requiere haber iniciado sesión con /login y no funciona dentro de WSL.

Terminal 
claude --chrome

Guía de Claude en Chrome

Claude Tag en Slack

La antigua integración «Claude Code en Slack» se retiró. Su reemplazo es Claude Tag: mencionas a Claude en un canal y cada hilo queda respaldado por una sesión remota. Está disponible solo en planes Team y Enterprise.
