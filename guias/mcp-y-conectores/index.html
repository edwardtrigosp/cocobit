MCP y conectores

MCP (Model Context Protocol) conecta Claude con tus herramientas: diseño, documentos, tickets, bases de datos y más.

Lectura: 6 minRevisado: noviembre de 2026
En esta página

  2. Añadir un servidor remoto (HTTP)
  3. Añadir un servidor local (stdio)

Qué es MCP

Un servidor MCP le da a Claude herramientas nuevas: leer un diseño de Figma, crear una página en Notion, consultar un issue. Los servidores remotos se conectan por HTTP; los locales se ejecutan como un proceso (stdio) en tu equipo.

Añadir un servidor remoto (HTTP)

Es la opción recomendada para servicios en la nube:

Terminal 
claude mcp add --transport http notion https://mcp.notion.com/mcp

Luego, dentro de Claude Code, abre /mcp para iniciar sesión (OAuth), reconectar o desactivar servidores.

Si el servicio usa un token en lugar de OAuth:

Terminal 
claude mcp add --transport http api-segura https://api.ejemplo.com/mcp --header "Authorization: Bearer TU_TOKEN"

SSE está obsoleto. Si un proveedor ofrece HTTP y SSE, elige HTTP.

Añadir un servidor local (stdio)

Las opciones van antes del nombre, y -- separa las opciones de Claude del comando del servidor:

Terminal 
claude mcp add --transport stdio --env AIRTABLE_API_KEY=TU_CLAVE airtable -- npx -y airtable-mcp-server

Alcances y .mcp.json

--scopePara quiénDónde se guarda
local (por defecto)Solo tú, en este proyecto~/.claude.json
projectTodo el equipo.mcp.json en la raíz
userSolo tú, en todos los proyectos~/.claude.json
.mcp.json 
{
  "mcpServers": {
    "servidor-compartido": {
      "type": "http",
      "url": "https://example.com/mcp"
    }
  }
}

Claude Code te pide aprobación antes de usar los servidores de .mcp.json. Admite variables como ${VAR} y ${VAR:-valor}, así los tokens no quedan en Git.

Gestionar servidores

Terminal 
claude mcp list
claude mcp get notion
claude mcp remove notion

Conectores en Claude.ai

En la app y la web de Claude, los conectores son la forma más sencilla de usar MCP: se activan desde los ajustes de tu cuenta, sin comandos. Algunos se sincronizan con Claude Code; consulta la documentación de MCP para ver los detalles.
