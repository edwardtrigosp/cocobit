Skills, plugins y subagentes

Convierte lo que repites en skills, instala plugins de la comunidad y delega trabajo en subagentes especializados.

Lectura: 8 minRevisado: noviembre de 2026
En esta página

  2. Crea tu primera skill
  3. Instala plugins

Qué es una skill

Una skill es una carpeta con un archivo SKILL.md: instrucciones que Claude carga cuando las necesita. La invocas con /nombre, o Claude la usa sola cuando la description encaja con lo que pides.

ÁmbitoRuta
Personal~/.claude/skills/<nombre>/SKILL.md
Proyecto.claude/skills/<nombre>/SKILL.md
Plugin<plugin>/skills/<nombre>/SKILL.md (se llama como /plugin:skill)

Crea tu primera skill

  1. Crea la carpeta .claude/skills/resumen-cambios/ en tu proyecto.

  2. Dentro, crea SKILL.md:

    SKILL.md 
    ---
name: resumen-cambios
description: Resume los cambios sin confirmar y señala riesgos. Úsala cuando el usuario pregunte qué cambió.
allowed-tools: Bash(git diff *)
---

Resume en dos o tres puntos lo que muestra `git diff HEAD` y lista los riesgos.

  3. Úsala escribiendo /resumen-cambios, o pregunta «¿qué cambió?» y Claude la cargará sola.

Clave: la description decide cuándo se usa la skill. Escríbela como «qué hace + cuándo usarla». Si no quieres que se active sola, añade disable-model-invocation: true.

Los comandos antiguos en .claude/commands/*.md siguen funcionando, pero ahora se recomiendan las skills. Si hay un comando y una skill con el mismo nombre, gana la skill.

Instala plugins

Un plugin empaqueta skills, agentes, hooks y servidores MCP. Se instalan desde marketplaces; el oficial, claude-plugins-official, se añade solo en tu primera sesión.

Dentro de Claude Code 
/plugin
/plugin install commit-commands@claude-plugins-official
/plugin marketplace add owner/repo

Desde la terminal:

Terminal 
claude plugin install <plugin>@<marketplace> --scope project
claude plugin list
claude plugin update <plugin>@<marketplace>

El alcance user aplica a todos tus proyectos; project se comparte con el equipo en .claude/settings.json; local es solo tuyo en este proyecto.

Subagentes

Un subagente es un asistente especializado con su propio contexto y sus propias herramientas. Claude le delega trabajo y recibe un resumen, así la conversación principal no se llena de detalles.

Guárdalos en .claude/agents/ (proyecto) o ~/.claude/agents/ (usuario). Solo name y description son obligatorios.

.claude/agents/revisor-codigo.md 
---
name: revisor-codigo
description: Revisa calidad y seguridad tras cambios de código.
tools: Read, Grep, Glob
model: sonnet
---

Analiza el código y da retroalimentación concreta sobre calidad, seguridad y buenas prácticas.

También puedes pedirle a Claude que cree el subagente por ti. Ya trae algunos integrados, como Explore y Plan.
