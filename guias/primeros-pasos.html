CLAUDE.md: la memoria del proyecto

CLAUDE.md es un archivo Markdown con instrucciones que Claude lee al empezar cada sesión: cómo se ejecutan los tests, qué convenciones sigue tu equipo, qué no debe tocar.

Dentro de Claude Code 
/init

/init analiza el proyecto y crea un primer CLAUDE.md. Edítalo luego con /memory.

ÁmbitoArchivoQuién lo ve
Usuario~/.claude/CLAUDE.mdSolo tú, en todos tus proyectos
Proyecto./CLAUDE.md o ./.claude/CLAUDE.mdTodo el equipo (va en Git)
Local./CLAUDE.local.mdSolo tú en este proyecto (añádelo a .gitignore)

Modos de permisos

Pulsa Shift+Tab para recorrer los modos. El ciclo normal es manual → aceptar ediciones → plan; la barra de estado indica cuál está activo.

ModoQué hace
defaultPide permiso antes de editar archivos o ejecutar comandos.
acceptEditsAcepta las ediciones de archivos sin preguntar.
planSolo investiga y propone un plan; no cambia nada hasta que lo apruebas.
autoAparece en el ciclo solo si está habilitado y se cumplen los requisitos.
Terminal 
claude --permission-mode plan

Cuidado: bypassPermissions desactiva todas las confirmaciones. Úsalo solo en entornos aislados, como un contenedor desechable.

Plan mode: piensa antes de tocar

Para tareas grandes, empieza en plan mode: Claude explora el código, te hace preguntas y propone un plan que tú apruebas antes de cualquier cambio.

Dentro de Claude Code 
/plan migrar la autenticación a OAuth

Comandos de cada día

ComandoPara qué sirve
/clearEmpieza una conversación nueva con el contexto vacío.
/compactResume la conversación para liberar contexto. Acepta instrucciones.
/resumeRetoma una conversación anterior.
/model · /effortCambia el modelo y el nivel de razonamiento.
/contextMuestra qué ocupa la ventana de contexto.
/usageCoste de la sesión y límites del plan. /cost es un alias.
/configAjustes interactivos.
/helpLista de comandos disponibles.

Retomar desde la terminal

Terminal 
claude -c
claude -r "auth-refactor" "Termina el PR"

-c continúa la conversación más reciente de la carpeta; -r reanuda una por ID o nombre.

Consejos para pedir mejor

  • Sé concreto: menciona archivos con @ y di cómo sabrás que está bien hecho (por ejemplo, «que pasen los tests»).
  • Divide: una tarea grande sale mejor como plan con pasos que como una sola petición.
  • Limpia el contexto con /clear al cambiar de tema; Claude rinde mejor con contexto enfocado.
  • Guarda lo que repites en CLAUDE.md o conviértelo en una skill.
